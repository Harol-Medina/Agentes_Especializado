# Lecciones Aprendidas

Registro acumulativo de errores y correcciones realizadas durante el desarrollo. Cada entrada documenta qué salió mal, por qué, y cómo evitarlo en el futuro.

Este archivo se actualiza automáticamente via hook cuando Kiro se autocorrige tras un code review.

---

## Formato de Entrada

```
### [YYYY-MM-DD] Título breve del problema

- **Qué pasó**: Descripción del error o problema
- **Causa raíz**: Por qué ocurrió
- **Corrección**: Qué se hizo para arreglarlo
- **Lección**: Regla o patrón a recordar para evitar recurrencia
- **Archivos afectados**: Lista de archivos modificados
```
